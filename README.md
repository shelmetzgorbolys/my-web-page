# my-web-page

Сайт-резюме Дениса Кудухова — Junior Frontend-разработчика.

Стек: Vue 3, TypeScript, Vite. В продакшене — статика за nginx в Docker.

## Запуск через Docker Compose

```bash
docker compose up -d --build
```

Сайт откроется на http://localhost:8080. Другой порт: `PORT=3000 docker compose up -d --build`.

Остановить: `docker compose down`.

## Локальная разработка

```bash
npm install
npm run dev
```

## Где менять содержимое

Весь текст резюме лежит в [src/data/resume.ts](src/data/resume.ts) — компоненты менять не нужно.

## Что внутри

- Монохромный 1-bit стиль: пиксельные шрифты (Press Start 2P, Handjet), дизеринг, окна в духе старых ОС.
- Экран загрузки «BIOS» (один раз за сессию), печатная машинка, расшифровка заголовков, глитч-помехи.
- Интерактивный терминал с командами, автодополнением по Tab и историей (↑/↓). Открывается по `Ctrl/⌘ + K` или `/`.
- Статус-бар: текущий раздел, прогресс прокрутки, FPS, часы.
- Пасхалка: ↑ ↑ ↓ ↓ ← → ← → B A.
- Светлая и тёмная темы, учёт `prefers-reduced-motion`, без внешних зависимостей в рантайме, кроме Vue.

Команды терминала описаны в [src/terminal/commands.ts](src/terminal/commands.ts) — новую команду можно добавить одной записью.
